Course Description

This course addresses the fundamentals and practical application of microcontrollers (\(\mu\text{Cs}\)) to design and implement reliable embedded systems.

Students learn the distinction between microprocessors and microcontrollers, memory-mapped peripheral architectures, deterministic real-time constraints, and low-level firmware engineering using Embedded C. The curriculum covers low-level bitwise operations, register manipulation, clock distribution, timers, pulse-width modulation (PWM), interrupt service routines via the NVIC, and standard serial communication protocols (UART, SPI, I2C).

12-Week Course Curriculum

Week Module Title Core Focus Areas Status
Week 1 Introduction to Embedded Systems & Microcontrollers Real-Time constraints, MCU vs MPU, Von Neumann vs Harvard, ARM Cortex series Open Notes & Sim →
Week 2 Basics of Embedded C Programming Bitwise operators, Bitmasking, volatile keyword, Memory-mapped I/O Open Module →
Week 3 Intermediate STM32 Programming & Architecture ARM Cortex-M core, AHB/APB buses, RCC clock gating, GPIO configuration Open Module →
Week 4 Advanced Peripheral Interfacing Hardware Timers, Prescaler, Auto-Reload, PWM generation, NVIC Interrupts, ADC Open Module →
Week 5 Communication Protocols in Embedded Systems Parallel vs Serial, UART, SPI, I2C, Networking Concepts & Fieldbus Protocols Open Module →
Week 6 Compilation, Runtime, Memory & Power Management Compilation stages, Linking, Memory Layout (.text, .data, .bss), Boot sequence, Power modes Open Module →
Week 7 Programming Assignments & Hands-on Lab Priority Traffic Signal, Hardware Timers, 50 Hz PWM Servo Control Open Module →
Week 8 Software Architecture & Embedded Design Patterns Finite State Machines (FSM), Observer Pattern, Layered Architecture, Error Handling Open Module →
Week 9 Real-Time Operating Systems (RTOS) FreeRTOS Core, Tasks & TCB, Preemptive Scheduling, Queues, Semaphores, Mutexes Open Module →
Week 10 Efficient Embedded Systems & Optimization Interrupts vs Polling, DMA Transfers, Cache Memory Systems, Power & Code Optimization Open Module →
Week 11 Testing, Debugging & Performance Profiling In-Circuit Debugging, JTAG/SWD, DWT Cycle Profiling, Static Analysis, Unit Testing Open Module →
Week 12 Safety, Security & Professional Ethics Functional Safety, Fail-Safe Design, Embedded Cybersecurity, Engineering Ethics, MISRA-C Open Module →
